# 🎯 拼音过关练习

基于《拼音一天一过关练习》PDF 制作的拼音练习小程序（H5 网页应用），手机、平板、电脑浏览器均可使用。

## ✨ 功能

- **19 个关卡**：与原练习册章节一一对应（单韵母、声母、三拼音、复韵母、前后鼻韵母、总复习）
- **🎲 随机抽取**：每关随机抽题，本轮内绝不重复；重复的练习项已在题库中去重；抽取后只显示题目，**不会自动朗读**，需要听发音时点「朗读」
- **🔊 真人朗读**：全部发音为真人语音（见下方音频来源），每项只播放一种声音（整词播放，绝不重复叠加）
- **📕 记错**：读错的拼音一键记入错题集；错题集可随时**移除**单项、清空、或整体再练习
- **🔄 重新开始**：随时重置本轮，重新洗牌、计时归零
- **⏱ 计时**：每轮自动计时，闯关记录**最快用时**（🏆 新纪录提示）
- **📱 多端适配**：手机竖屏单栏布局；**平板横屏自动切换双栏布局**（左侧大字题目卡 + 计时进度，右侧四个功能按钮 + 历史记录）
- 声调彩色显示（一声红、二声橙、三声绿、四声蓝），历史记录可点击重听

## 🚀 使用方法

1. **电脑**：直接用浏览器打开 `index.html`（推荐 Chrome / Edge）
2. **手机**：把整个 `拼音过关练习` 文件夹发到手机，用浏览器打开 `index.html`；
   安卓 Chrome / iOS Safari 可"添加到主屏幕"，像 App 一样使用，**完全离线可用**

## 📁 文件说明

| 文件 | 说明 |
| --- | --- |
| `index.html` | 主程序（单文件，含界面与逻辑） |
| `data.js` | 19 关题库数据（1423 个练习项） |
| `audio/` | 全部真人发音（约 1700 个音节 + 145 个词语） |
| `manifest.json` / `icon.png` | 添加到主屏幕用的应用清单与图标 |

## 🔊 音频来源（真人发音，保证准确）

- **音节发音**（1707 个）：陈旺（Chen Wang）老师真人录音，来自开源项目 [hugolpz/audio-cmn](https://github.com/hugolpz/audio-cmn)（64k 音质版），许可 CC-BY-SA
- **词语发音**（145 个）：微软晓晓（XiaoxiaoNeural）真人语音合成，由真人配音演员录制训练的神经网络语音，普通话标准
- 题库由原练习册扫描页 OCR 重建，并依据《汉语拼音方案》校验声调合法性；每章按练习册编排声母/韵母范围，声调采用"四声全覆盖"式训练

## 🛠 题库维护

题库构建脚本与音频下载脚本位于上级目录（`build_chapters.py`、`download_audio.py`、`gen_words.py`），可重新生成。
